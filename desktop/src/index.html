    This runs your local keytool to read the public certificate fingerprint only. The keystore file and password never leave your machine and are not saved by this app.

    Manual equivalent: keytool -list -v -keystore your.jks -alias yourAlias or apksigner verify --print-certs app-release.apk. Never paste your actual keystore file or password anywhere except this tool's own keystore loader above — only the resulting fingerprint is meant to be shared.
